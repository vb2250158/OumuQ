## Banner 设计目标

这张 banner 需要让读者在 GitHub README 第一屏就知道项目用途：

- 项目名：OumuQ
- 核心定位：角色驱动的本地 TTS 路由系统
- 核心机制：用“人格证”选择说话者
- 主要能力：参考音色匹配、异步生成、顺序播放

## 版式规范

- 推荐比例：约 `2.4:1`
- 推荐尺寸：`1942x809` 或等比例缩放
- 左侧放清晰文字说明
- 右侧放 OumuQ 看板娘
- 避免文字太小、背景太花、卡片元素太多
